# TUI：终端交互与遥测

[架构总览](README.md) · [操作与快捷键](../GUIDES/INTERFACES.md#interactive-tui)

TUI 是可选交互入口，共用 SessionManager、Agent、Tools 和 Permissions。它持有编辑草稿、显示状态与终端生命周期，不拥有第二份持久历史或执行规则。

## 模块与数据流

实现位于私有 workspace 包 `@fatcat/tui`，通过包根直接导出 `runTui`。CLI 完成参数校验和输入所有权交接后才惰性加载该入口；导入本身不接管 stdin、注册信号处理或调用模型。TUI 依赖 runtime、commands 和原有 pi-tui，独立生成 JavaScript 与类型声明，没有新的终端框架或状态所有者。

原根 `tui/` 实现已迁走，不保留路径转发。离线测试仍集中在 `packages/verification/tests/tui/`；测试和原生验证脚本通过 `@fatcat/tui/internal/*` 访问 App、视图与遥测，生产代码只使用包根。包依赖与导出规范见[开发说明](../DEVELOPMENT.md#workspace-package-boundaries)。

| 源码 | 职责 |
| --- | --- |
| `packages/tui/src/index.ts` | 配置与共享核心装配，注入审批回调 |
| `packages/tui/src/app.ts` | 输入、运行/审批状态、AbortController、命令和终端收尾 |
| `packages/tui/src/presentation.ts` | 无状态的事件显示转换，以及写入、命令、浏览器审批说明格式化 |
| `packages/tui/src/view.ts`、`theme.ts` | Markdown、宽度、布局、颜色与控制字符处理 |
| `packages/tui/src/telemetry.ts`、`metrics.ts` | 本轮/进程、父子、最新请求与缓存覆盖的事件观察 |
| `packages/commands/src/commands.ts` | 本地命令分发；具体语义归核心模块 |

编辑提交 → Manager 执行 → 事件/报告 → 遥测快照 → 视图。只有持久边界确认后才增加已保存回合。工具等待独立审批输入，界面答复不进入模型历史；授权后工具仍自行复核。

使用 pi-tui 的编辑、Markdown 和宽度/渲染能力，避免另引终端运行时或复制 Agent 循环。chat 继续由 terminal.ts/readline 持有输入，不与 TUI 同时消费。

## 回合执行与显示反馈边界

`TuiApp.beginOperation()` 在调用 Session 前建立取消控制器、busy、编辑器提交状态和计时；普通输入和自动任务再调用 `beginTurn()` 重置本轮显示去重并开始遥测。普通本地命令不重置这些观察，显式 `/compact` 单独开始摘要遥测。共同初始化不改变编辑草稿，也不把回合状态迁入辅助模块。

`runLocalCommand()` 和 `runTurn()` 保留各自收尾：本地命令按结果恢复会话或更新页脚，摘要不增加对话回合数，命令错误不设置进程失败标志；普通/自动回合按实际结果统计成功或失败，后台目标与前台会话不同时恢复前台对话计数。审批、取消、最终刷新、退出等待和终端恢复仍由 App 协调。

事件先交给 telemetry 观察，再由 App 判断显示资格，最后调用 `eventPresentation()` 生成活动提示与消息，并按原顺序追加、刷新。写入以 ID 和完整记录指纹去重，记录变化仍显示；命令按 ID 去重。父子事件共用 App 的去重集合，报告仍展示完整汇总和过期证据提示；隐藏重复消息不影响遥测。

`presentation.ts` 不持有 Session、App、编辑器、journal 或可变缓存，不执行工具、不发起审批、不修改事件。审批格式化只接收请求及当前工作目录；审批新输入、草稿隔离和授权后的工具复核保持原有所有权。显示文本的终端转义处理仍由 view 负责。后续修改遵循[开发规范](../DEVELOPMENT.md)中的 TUI 边界。

## 输入、显示与取消

运行中可以编辑下一条草稿，但不会自动排队/提交，粘贴不隐式发送。审批先保存并清空草稿，使用当前操作的新输入，结束后恢复；此前待处理输入不能被消费为批准。文件预览有界并标截断，命令显示完整内容和执行范围。

取消传播到父子模型与工具，收尾后返回输入；退出另有生命周期，停止绘制并恢复模式/光标。局部 Terminal 适配优先处理取消和滚动，Kitty 释放包不能重复触发。TUI 的取消后继续交互不代表 chat 的 Ctrl+C 语义相同。

宽度至少 110 列采用侧栏，窄/短终端降级布局，完整值可通过 /status 查看。显示文本移除 ANSI/OSC/C0/C1 控制字符，再渲染 Markdown；NO_COLOR 禁主题色。终端能力仍决定字符宽度、输入法与颜色表现。

会话切换重建用户/assistant 显示，不伪造旧遥测。自动任务空闲运行并保留草稿，使用目标会话，前台选择不变。新建/reset 不清除进程累计、工具 journal、权限或副作用。

## 指标口径

| 指标 | 数据来源与含义 |
| --- | --- |
| 配置/目录/权限 | 当前 Config、规范工具根和策略，不是模型自述 |
| 回合 | 当前运行与成功保存计数，失败展示不等于已保存历史 |
| 请求 | 父子尝试数，含本地预算拒绝，不是 HTTP/计费次数 |
| token | 已校验服务数据，展示已知覆盖、父子及本轮/进程累计 |
| 最近输入 | 最新普通父请求 prompt tokens，不含未发送草稿或最终回复 |
| request bytes | 最新完整 JSON 与本地预算，独立于 token 窗口 |
| 缓存 | 有效命中/同批输入的加权率和覆盖，不是 KV 容量或费用 |
| 执行 | 真实工具/日志/报告，不推断任务成功 |

未知/非法/溢出计数保持未知，合法零不同于缺失；失败前有效用量保留。telemetry 从原始事件计算，不能再次累加报告总量。字段合法性归 [Providers](PROVIDERS.md)，操作事实归 [Execution reports](EXECUTION_REPORT.md)。

TUI 不猜测模型 token 窗口；本地 bytes 进度不能代替容量。每次新父请求清空旧观察，摘要/文档辅助请求计入用量但不冒充聊天上下文。自动 compact 仍是一轮，不额外增加对话计数。

## 验证与后续要求

离线检查覆盖尺寸、指标缺失/冲突、父子去重、写入状态更新与跨回合显示、同步审批、本地命令错误、审批输入隔离、取消/reset、终端恢复。

`pnpm run verify:tui` 在真实 Windows 终端中启动注入模型夹具，使用 ProcessTerminal 和临时工作目录；按[开发指南](../DEVELOPMENT.md)中的步骤输入，验证真实写入审批、草稿恢复、显式摘要、取消后继续、滚动和退出。夹具退出时断言文件内容、模型收到的输入、历史、统计、raw mode 和信号监听器恢复，成功输出 `passed: true`；终端控制序列和页面反馈需在交互时检查。它不加载 `.env` 或访问模型 API，也不验证真实供应商缓存质量、完整 IME 候选窗口或模型任务效果。

后续交互改进继续沿当前所有权边界，针对输入、审批、取消和反馈做离线回归与原生 Windows 终端验收，并保留普通 CLI。尚无冻结的新布局或排期。

未新增流式答案、思考历史、provider 热切换、费用估算或任务验收引擎；恢复不重建旧过程遥测。不能以渲染单测代替实际终端可用性。
