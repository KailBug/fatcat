## 2026-09-21：阶段 2D-1，通用 read 工具

### 实际结果

- 本轮将 list_directory / read_file 合并为一个 read 工具；默认仍只有 sum，显式 --workspace 后增加 read，原名称移除。
- 输入 path、可选 offset / limit：目录先过滤和排序再分页，文件按行分页；结果提供类型、总量、行号及 nextOffset，空页和末页明确结束。
