<h1 align="center">Fatcat</h1>

<p align="center"><a href="../README.md">English</a> | 简体中文</p>

一个用于本地编程实验的小型 TypeScript Agent Harness demo，支持 DeepSeek、Kimi、MiMo 和 Qwen，原生运行于 Windows。

项目仍处于早期 demo 阶段，目前支持简单的 Agent Loop、CLI 对话、本地 Skills 的按需读取、工作目录读取、文本搜索与受控编辑、经授权的 Windows 命令执行，根据任务选择的有界子 Agent 委派，有界模型请求与超限时的旧读取内容省略，以及每回合的执行和 token 用量报告。新增三家供应商按官方协议进行离线验证，本轮未做 API 在线验证。
