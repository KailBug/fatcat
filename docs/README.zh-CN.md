一个用于本地编程实验的小型 TypeScript Agent Harness demo，支持 DeepSeek、Kimi、MiMo 和 Qwen，原生运行于 Windows。

可通过 CLI 对话、TUI 或本地 Web UI 检查工作区、受控修改文件并运行验证；各入口共用持久会话、工具与权限边界。项目仍处于早期 demo 阶段，具体操作、支持范围与验证限制见文档。
