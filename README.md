<h1 align="center">Fatcat</h1>

<p align="center">English | <a href="docs/README.zh-CN.md">中文</a></p>

A small TypeScript agent harness demo for local coding experiments, with configurable DeepSeek, Kimi, MiMo, and Qwen providers, built to run natively on Windows.

Still an early demo, with a simple agent loop, CLI chat, local skills loaded on demand, workspace reading, text search and controlled editing, approved Windows command execution, bounded task-driven delegation, bounded model requests with conditional omission of older read outputs, and per-turn execution and token usage reports.

[Setup and usage](docs/USAGE.md)
